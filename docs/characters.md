# キャラクター設定（たたき台 v0.1）

チャンネル設計 v1.0（`docs/channel-design.md`）を前提にした、固定キャラクターの設定です。
役割は「A＋友人を準レギュラー」（主人公を固定し、対比役の友人も毎回同じ人物）で確定済み。

---

## 共通のルール

- **教えない：** 説明はナレーターだけが担当する。キャラクターは「答えを知っている人」にならない
- **体験談を語らない：** 「僕はこうやって克服した」とは言わない（人格頼みの路線に戻るため）
- **セリフは字幕：** 声はナレーターだけ。キャラクターのセリフは字幕か吹き出しで見せる
- **1本で完結：** どの回から見ても分かるよう、毎回その回の悩みだけを扱う。成長は「その回の悩みが少しほどける」まで。前の回を見ていないと分からない話にはしない
- **見た目のルール：** `docs/channel-design.md` の4章（スタイル統一ルール）に従う

## 友人（準レギュラー・対比役）

| 項目 | 内容 |
| --- | --- |
| 名前（案） | ①タク　②ソラ　③ケンタ |
| 役割 | その回の悩みを「なぜか自然にできている人」。最後に種明かしをする |
| 基本 | 21歳、男子、主人公と同じゼミ。バイトは古着屋 |
| 見た目（案） | 白い丸い頭に、短めのゆるいくせ毛（こげ茶）。マスタード色のカーディガン。目は主人公より少し開いた穏やかな目 |
| 性格 | 自然体で、よく笑う。人の話を面白がる。自分のことを話し上手だとは思っていない |
| 種明かしの型 | 「え、話すこと考えるの、実は苦手なんだよね」のように、弱さや意外な本音を見せる。そこから、その回の核心（原則）につながる |
| 主人公との関係 | 1年の頃からの友達。主人公の失敗を笑わない。でも答えも教えない |
| しないこと | アドバイスする、「こうすればいいよ」と教える、完璧な人として描かれる（毎回どこか一つ抜けている） |

### なぜ友人は「教えない」のか
友人が答えを教えると、友人が「信頼を背負う人格」になり、引き継ぎメモで避けると決めた路線に戻ります。
友人は「自分では意識していない」だけで、その仕組みをナレーターが言葉にして説明する、という役割分担にします。

## 今後増やすかもしれない人物

| 人物 | 役割 | 登場のしかた |
| --- | --- | --- |
| 好きな人 | 恋愛や距離感の回の相手役 | 必要な回だけ。攻略の対象としては描かない |
| バイトの先輩 | 断れない、上下関係の回の相手役 | 必要な回だけ |
| 1年生の後輩 | サブのペルソナ（高校生〜入学直後）向けの回の主人公役 | 入学シーズンの回で主人公の代わりに悩む |
| モブ | 教室、学食などの背景の人 | 顔なしのグレー |

新しい人物を作るときは、4章のルール（髪、服の色、小物1つ、目つき）だけを変え、全員を並べた静止画で確認してから使います。
