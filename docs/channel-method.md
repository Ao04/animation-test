# チャンネルの作り方（変化から逆算する方法）

ジャンルを問わず、新しいYouTubeチャンネルを作るときに使う方法のメモ。
コミュニケーションのチャンネルを設計したときに固まった考え方を、AI系など別のジャンルでも使えるようにまとめたもの。

---

## 考え方の核：東京駅と路線

| | たとえ | チャンネルでいうと |
| --- | --- | --- |
| 東京駅 | ゴール。一つに決める | 動画を見続けた視聴者が、最終的にたどり着く状態（変化） |
| 路線 | 東京駅へ行く電車。何でもいい | 一本一本の動画の企画 |

- ゴールは一つに、はっきり決める。
- 路線（企画）は自分から減らさない。どんな企画でも、同じ駅に着けばよい。
- 差別化は、ジャンルや出発点を狭めることではなく、**ゴールの中身**でつける。

ジャンル（「フィットネス」「YouTubeの伸ばし方」など）を選ぶだけでは、同じテーマの数千のチャンネルに埋もれる。
大事なのは、見終わった視聴者が何を知り、どう感じ、どう変わるかという**変化（Transformation）**をはっきり示すこと。

---

## 手順

### 1. 変化の一文を書く
> **〔今の状態の人〕を、〔ゴールの状態〕に変えるチャンネル**

- **今の状態：** 広く、でも絵が浮かぶ言葉で書く。細かく限定しすぎると、乗れる路線が減る。
- **ゴールの状態：** よくあるゴールとは違う中身にする。ここで差別化する。

例（YouTube運営系）：
- ジャンルだけ：YouTubeの伸ばし方を解説するチャンネル
- 変化の一文：ロボットのように魂のない動画を作っている人を、人間味のある魅力的でリアルな動画を作れるように変えるチャンネル

### 2. ゴールで差別化できているか確かめる
同じジャンルでよくあるゴールを並べ、自分のゴールがそれと違うかを見る。

| よくあるゴール | 自分のゴール |
| --- | --- |
| （例：話し上手になる、最新情報を知る、稼げる） | （違う中身になっているか） |

### 3. 路線テストをする
企画を10個ほど書き出し、すべてがゴールに着くかを確かめる。

- 全部着く → ゴールは広さも、はっきりさも十分。
- 着く企画が少ない → ゴールか「今の状態」が狭すぎる。
- どれでも着いてしまい、何のチャンネルか分からない → ゴールがぼやけている。

### 4. 視聴者アバターを1〜2人決める
メインとサブの2人まで。年齢、状況、悩み、心の声、本当に欲しいもの、一番こわいこと、知識レベル、いつどう見るか、を書く。
知識レベルとトーンを外さないためのもの。

### 5. 共通のフォーマットを決める
毎回同じ流れ、同じお約束にして、1本気に入った人が過去の動画も続けて見るようにする（連続視聴）。

## よくある失敗
| 失敗 | 何が起きるか |
| --- | --- |
| ジャンルだけ決める | 同じテーマのチャンネルに埋もれる |
| 出発点を細かく決めすぎる | 扱える企画が減り、すぐネタ切れする |
| ゴールがありきたり | 「他でも見られる」と思われる |
| 語り手の人格や体験談を価値の中心にする | AIや匿名での運営では信頼が積み上がらない。情報の整理と見せ方を価値にする |

---

## 記入例1：コミュニケーションのチャンネル（このプロジェクト）
| 項目 | 内容 |
| --- | --- |
| 変化の一文 | 人の前で「ちゃんとした自分」を演じて疲れてしまう人を、素のままで人とつながれる人に変えるチャンネル |
| よくあるゴール | 話し上手になる、モテる、心理学に詳しくなる |
| 自分のゴール | 頑張らなくても、素のままで人とつながれる |
| 路線の例 | 会話が続かない、断れない、LINEの返信、新歓、飲み会、好きな人、先輩との距離、人と比べる、謝りすぎる |
| アバター | メイン：大学2年の男子／サブ：高校生〜入学直後の男子 |

## 記入例2：AI系のチャンネル（もし作るなら・未検証のたたき台）
| 項目 | 内容 |
| --- | --- |
| 変化の一文 | AIを試しては結局使わなくなる人を、AIを毎日の仕事や勉強に自然に組み込める人に変えるチャンネル |
| よくあるゴール | 最新のAIニュースを知る、新しいツールを知る、AIで稼ぐ |
| 自分のゴール | 新しいツールを追いかけなくても、AIが毎日の道具になっている |
| 路線の例 | 新ツールの紹介（「明日から使い続けられるか」の目線で）、レポートや資料作り、勉強法、プロンプトの型、失敗例、AIに任せない方がいいこと、ニュースの読み解き |
| アバター | （作るときに決める） |
