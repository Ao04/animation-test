# 参考チャンネル分析用 NotebookLM プロンプト

## 事前準備（精度が上がります）
NotebookLM は動画の文字起こししか読めず、再生回数や映像は見えません。動画20本に加えて、次の表をテキストのソースとして1つ追加してください。

```
番号 | タイトル | 再生回数 | 長さ | 公開日
1 | ... | ... | ... | ...
```

- 動画の選び方：再生回数の多い順に10本＋最近の10本（伸びた動画と普通の動画を比べられるように）
- 出力が途中で切れやすいので、プロンプトは3回に分けて送ります。結果はまとめて貼ってください。

---

## プロンプト1：チャンネル全体とフォーマット

```
あなたはYouTubeチャンネルの構成アナリストです。ソースの動画すべてを分析し、日本語で答えてください。

【ルール】
- 主張には、根拠になった動画のタイトルを（）で添えること。
- 文字起こしから確実に言えることは「確実」、推測は「推測」と明記すること。映像は見えないので、映像についての記述は推測扱いにすること。
- 引用は1文以内の短いものにし、要約を中心にすること。
- 表を使い、見出しは下の番号どおりにすること。

1. チャンネルの約束
  - 視聴者は見る前と見たあとで、何を知り、どう感じ、どう変わるか（表：見る前／見たあと）
  - チャンネルを一文で説明すると何か
  - 想定している視聴者像（年齢、性別、悩み、知識レベル）。根拠となる言い回しも挙げる

2. 動画の共通フォーマット
  - ほぼすべての動画に共通する流れを、パートごとに表にする（パート名、役割、全体の何%の位置か、よく使われる言い回しのパターン）
  - 毎回出てくる「お約束」（決まり文句、決まった問いかけ、決まった締め方）
  - フォーマットから外れている動画があれば、その動画と違い

3. タイトル
  - タイトルを型に分類し、型ごとの本数と例を表にする
  - 再生回数の表がソースにあれば、型ごとの平均的な伸び方の傾向

4. 伸びた動画と伸びていない動画の違い
  - 再生回数の表がある場合、上位5本と下位5本を比べて、テーマ・冒頭・構成・タイトルの違いを挙げる
  - 表がない場合はこの項目を省略する
```

## プロンプト2：台本の技法

```
引き続き、ソースの動画すべてを分析し、日本語で答えてください。ルールは前回と同じです（根拠の動画タイトルを添える、確実／推測を分ける、引用は1文以内）。

5. 冒頭（最初の30秒）
  - 冒頭の始め方を型に分類し、型ごとの本数と例を表にする
  - 視聴者を引き止めるために、最初の何秒で何をしているか

6. 説明の技法
  - 比喩：どんな比喩が使われているか、1本あたりの数、比喩の選び方の傾向
  - 数字や図式：数字、分類、段階、公式などをどう使っているか
  - 研究や根拠：研究の引用の頻度と言い方。仮説や経験則をどう断っているか
  - 具体例：架空の場面、視聴者への質問、ありがちな会話など、どれを多く使うか

7. 視聴者の参加
  - 一時停止させる、考えさせる、自分に当てはめさせる、などの仕掛けと、その位置

8. 語り口
  - ナレーターの人称（私・あなた・彼など）と、視聴者との距離感
  - ユーモアの種類（自虐、皮肉、誇張、ツッコミなど）と頻度。日本人に伝わりにくそうなものはどれか
  - 1文の長さ、テンポ、専門用語の量

9. 構成の技
  - 「一度言い切ってから例外を出す」「序盤の例を後半で再登場させる」などの構成の技を、見つかった分だけ列挙し、例を添える

10. 終わり方
  - 最後の30秒の型（まとめ、問いかけ、次の動画への誘導、チャンネル登録の頼み方）
```

## プロンプト3：キャラクターと映像、日本向けの調整

```
最後に、ソースの動画すべてを分析し、日本語で答えてください。ルールは前回と同じです。

11. 登場人物
  - 毎回出てくる人物はいるか。いる場合、それぞれの役割（主人公、対比役、案内役など）、性格、話し方
  - 人物が悩みから変化するまでの見せ方（冒頭と最後で何が変わるか）
  - ナレーターと登場人物の関係（ナレーターが人物に話しかけるか、など）

12. 映像を想像させる言葉（推測で構わない）
  - 文字起こしの中で、映像やアニメを前提にしている言い回し（「見て」「この図のように」など）
  - 1本の動画に出てくる場面（場所）の数と種類
  - 比喩が映像でどう見せられていそうか

13. 長さとテンポ
  - 動画の長さの分布
  - 1分あたりのおおよその単語数
  - パートごとの時間配分（全体の何%か）

14. 日本向けに調整するときの注意
  - 文化的に日本人に伝わりにくい場面、価値観、ジョーク
  - 日本の大学生向けに置き換えるとしたら、どの場面がどう変わりそうか（例を3つ）

15. まとめ
  - このチャンネルを真似するうえで、最も重要な要素を3つ
  - 真似してはいけない部分（そのチャンネル独自の比喩、キャラクター、決まり文句など、権利や独自性の面で避けるべきもの）
```
