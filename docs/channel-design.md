# チャンネル設計（シンプル版 v2.0）

動画制作を始めるための土台。細かいことは、動画を出しながら育てていく。
（以前の詳しい版は git の履歴に残っています）

---

## 1. 決まっていること
| 項目 | 内容 |
| --- | --- |
| ジャンル | 心理学・人間関係の解説（コミュニケーションが苦手な人向け） |
| 長さ | 最初の10本は約4分（ナレーション約1,200〜1,300字） |
| 声 | ナレーションのみ。キャラクターのセリフは字幕 |
| 絵柄 | 手描き風の線、紙の質感、暖かい夜の光 |
| キャラクター | 主人公（白い丸頭・ジト目・グレーのパーカー）＋準レギュラーの友人 |
| 台本 | テーマと参考台本を渡す → アウトライン → 4分の台本（Claude が書く） |
| タイトル | 「なぜ〇〇してしまうのか（〜）」と「〇〇する方法（〜しなくていい）」を交互に |
| 守ること | ナレーターもキャラクターも体験談を語らない。キャラクターは教えない |

## 2. 変化の一文（候補から1つ選ぶ）
「〇〇な人を、△△な人に変えるチャンネル」

1. 人の前で「ちゃんとした自分」を演じて疲れてしまう人を、素のままで人とつながれる人に
2. 人といると気をつかいすぎてヘトヘトになる人を、気をつかいすぎなくても好かれる人に
3. 会話のあと一人で反省会をしてしまう人を、人と会ったあと「楽しかった」が残る人に
4. 嫌われないことばかり考えている人を、自分から人と関われる人に
5. 「何を話せばいいか」で頭がいっぱいの人を、目の前の相手を楽しめる人に
6. 空気を読みすぎて自分が消えている人を、空気を読みつつ自分も出せる人に
7. 人間関係を「うまくやらなきゃいけないもの」だと思っている人を、「うまくやらなくていい」と思える人に
8. 人付き合いで元気を削られている人を、人と会って元気をもらえる人に
9. 自分から話しかけるのが怖い人を、小さな一歩で人と仲良くなれる人に
10. 「自分はコミュ障だ」と決めつけている人を、「やり方を知らなかっただけ」と分かる人に

## 3. ペルソナ
- **メイン：** 大学2年の男子（20歳）。雑談が続かない。嫌われてはいないけど、誰とも深く仲良くなれていない気がする。寝る前にスマホで見る。
- **サブ：** 高校3年〜大学1年の男子（18歳）。入学直後の友達作りが不安。短い動画に慣れていて、最初の10秒で見るかどうかを決める。

## 4. 動画のフォーマット（v0：出しながら育てる）

| --- | --- | --- | --- |
| 1 | 冒頭 | 0:00〜0:25 | 主人公の「あるある」な失敗 →「なぜ、こうなるのか。」→「一番効く方法は最後に」 |
| 2 | 仕組み | 0:25〜1:10 | なぜそうなるのかを、比喩1つで見せる |
