# チャンネル設計（たたき台 v0.2）

心理学・人間関係の解説チャンネル。引き継ぎメモの決定事項と、参考チャンネルの分析（NotebookLM、10本）を前提にしたたたき台です。
確定したら版を上げ、別のチャットにもこのファイルを貼り付けて使います。

- v0.1：コンセプト、フォーマット、ペルソナ、キャラクターのスタイル統一ルール
- v0.2：参考チャンネルの分析を反映（6章を追加。2章のフォーマットと台本ルール、タイトルの型を更新）

---

## 1. チャンネルのコンセプト

### 視聴者の変化（Transformation）
ジャンル（心理学・人間関係）ではなく、見終わったあとに視聴者がどう変わるかを軸にします。

| | 見る前 | 見たあと |
| --- | --- | --- |
| 考え方 | 「うまくいかないのは自分の性格のせい」 | 「うまくいかないのには仕組みがある。仕組みなら変えられる」 |
| 気持ち | 自分だけがおかしい気がして、一人で抱えている | 「みんなそうなんだ」と分かって、少し楽になる |
| 行動 | 何をすればいいか分からず、考えるだけで終わる | 明日、一つだけ試してみることが決まっている |

**一文で言うと：** 人間関係の「なぜかうまくいかない」を、性格ではなく仕組みとして理解し、明日一つだけ試せる状態にする。

この小さな「試せた」の積み重ねが、最終的な目的である「自分に自信を持てる」につながります。
自信は「自信を持て」と言われて持てるものではなく、小さな成功の記録から育つものなので、チャンネルの役割は毎回の「一つ試せること」を渡すことです。

### 視聴者が受け取るもの（3つ）
1. **知る：** 悩みの下にある心理の仕組み（研究で分かっていることと、仮説を分けて伝える）
2. **感じる：** 「自分だけじゃなかった」という安心と、少しの笑い（主人公の無表情なツッコミ）
3. **できる：** 明日試せる具体的なやり方（1本につき1〜2個）

### やらないこと
- 恋愛テク・モテ攻略（「落とし方」系）にはしない（好きな人との会話は扱うが、「攻略」ではなく人間関係として扱う）
- 体験談で語らない（「僕はこうやって克服した」はしない。人格に頼る路線に戻るため）
- 心理テストや病名で決めつけない
- 不安をあおるタイトル（「これをやる人は嫌われる」など）に頼らない

### 信頼の作り方（語り手の人格を使わずに）
- **根拠の見える化：** 「研究で分かっていること」と「仮説・経験則」を毎回ことばで区別する
- **一貫した型：** 毎回同じ流れ・同じ主人公で、「このチャンネルは期待どおりのものをくれる」という信頼を作る
- **誠実な例外：** 「ただし、こういう場合は当てはまらない」を必ず入れる

## 2. フォーマット（連続視聴を生む共通の型）

### 動画の型（毎回同じ流れ）
参考チャンネルの時間配分（冒頭10%／仕組み20%／方法50%／まとめ20%）に合わせて調整しました。

| # | パート | 4分版の目安 | 割合 | 内容 |
| --- | --- | --- | --- | --- |
| 1 | 冒頭シーン | 0:00〜0:25 | 約10% | 主人公の「あるある」な失敗の瞬間。最後に「一番効く方法は最後に」と予告する |
| 2 | 仕組み | 0:25〜1:10 | 約20% | なぜそうなるのか。比喩を1つ、アニメで見せる。研究か仮説かを言い分ける |
| 3 | 方法 | 1:10〜3:10 | 約50% | 明日試せるやり方（1〜2個）。悪い会話と良い会話を並べて見せる。途中で一時停止クイズと高評価のお願い |
| 4 | 核心とラストシーン | 3:10〜4:00 | 約20% | 友人の種明かし → 冒頭と同じ場面で変わった主人公 → 持ち帰る一言のカード → 今週試すこと一つ |

### 毎回入れる「お約束」（シリーズ感を作る）
| お約束 | 位置 | 内容 |
| --- | --- | --- |
| 冒頭の問い | 冒頭シーンの直後 | 主人公の失敗のあと、ナレーターが同じ型で問いを立てる（例：「なぜ、こうなるのか。」） |
| 共感の高評価 | 全体の40〜50% | 「〜したことがある人は、高評価で教えてください」（あるある行動と結びつける） |
| 友人の種明かし | 核心 | 自然にできる友人が、最後に「実は○○が苦手なんだよね」と弱さを見せる |
| 持ち帰る一言のカード | 最後 | 毎回同じデザインのカードで「次からはこう考える」を出す |
| 今週の一つ | カードの直後 | 「今週、一回だけ〜を試してみてください」 |
| 決まりの締めの言葉 | 最後の一言 | チャンネル独自のもの（参考チャンネルの言葉は使わない。案は後で決める） |

### 台本で毎回使う技法
参考チャンネルの分析から、構成の技として取り入れるもの（名前や比喩はまねせず、技法だけを使う）。

1. **「半分正解」返し：** 主人公の行動をいったん認めてから、「でも、それが落とし穴だった」とひっくり返す
2. **一番効く方法は最後に：** 冒頭で予告して、最後まで見てもらう
3. **やりすぎの線引き：** 方法を教えた直後に「ただし、ここまでやると逆効果」をセットで出す
4. **冒頭の場面の回収：** 冒頭の失敗場面を、最後に同じ場面での成功として描き直す
5. **数字で見せる仕組み：** 「質問4つ×30秒で2分」のように、簡単な計算で仕組みを見せる（仮説なら「これは研究ではなく、目安です」と断る）
6. **一時停止クイズ：** 「この一言に、話を広げる手がかりはいくつある？」と考えてもらう

### 語り口のルール
| 項目 | ルール | 参考チャンネルとの違い |
| --- | --- | --- |
| 人称 | 視聴者を「あなた」と呼ぶ。ナレーターは「私」を使わない | 参考チャンネルは「私も昔は同じ失敗をした」と語るが、これは人格頼みになるのでしない。失敗は主人公が引き受ける |
| 視聴者と主人公 | 「あなたにも、こんな経験はありませんか？」と問いかけ、主人公に演じさせる | 参考チャンネルは「あなた」だけで場面を想像させる。こちらは主人公を見せるので、映像で一目で伝わる |
| 文 | 1文を短く。テンポよく。専門用語は1本に1つまで、必ず言いかえる | 同じ |
| ユーモア | 主人公の無表情なツッコミと自虐。皮肉やいじりは使わない | 参考チャンネルのいじり・皮肉は日本では失礼に取られやすい |
| 文字数 | 4分で約1,200〜1,300字（1分あたり約300〜330字） | 参考チャンネルは8〜15分。4分版は方法を1〜2個に絞る |

### タイトルの型（候補）
参考チャンネルでは「〜する方法（How to）」が半分を占め、半数のタイトルに（　）で条件を添えています。

| 案 | 型 | 例 |
| --- | --- | --- |
| A | なぜ〇〇してしまうのか（〜） | なぜ、会話は3往復で終わるのか（ネタ不足ではない） |
| B | 〇〇する方法（〜しなくていい） | 会話が続く人になる方法（面白い話はいらない） |
| C | 〇〇な人の頭の中 | 会話が続かない人の頭の中 |

AとBを交互に使い、サムネイルは毎回同じ型（主人公の表情＋短いことば）にする案が有力です。

## 3. ペルソナ（視聴者アバター）

参考チャンネルの想定視聴者（20〜30代の男性。会話、恋愛、職場の人間関係に悩む）とも一致しています。

### メイン：大学2年生のハルト（仮名）
| 項目 | 内容 |
| --- | --- |
| 基本 | 20歳、男子、大学2年。地方出身で、大学進学を機に一人暮らし |
| 生活 | 授業、週3の飲食店バイト。サークルに入ったが、2年になって顔を出しづらくなっている |
| 人間関係の悩み | 雑談が2〜3往復で終わる。グループワークで沈黙が怖い。頼まれると断れない。LINEの返信を考えすぎて既読のまま半日たつ |
| 心の声 | 「嫌われてはないと思う。でも、誰かと本当に仲良くなれてる感じもしない」 |
| 本当に欲しいもの | 気をつかわずに話せる友達。自然体でいられる場所 |
| 一番こわいこと | 「空気が読めないやつ」「つまらないやつ」と思われること |
| 知識レベル | 心理学の用語は「承認欲求」くらいしか知らない。自己啓発本を1冊買って途中でやめた |
| 視聴のしかた | 寝る前、ベッドでスマホ。4分くらいなら最後まで見る。説教くさいとすぐ離脱。恋愛テクっぽいと引く |
| 刺さる言い方 | 自虐やツッコミのある軽いトーン。「あるある」から入る。専門用語は1本に1つまで |

### サブ：社会人1年目のソウタ（仮名）
| 項目 | 内容 |
| --- | --- |
| 基本 | 23歳、男子、新卒で入社1年目。営業事務 |
| 生活 | 平日は会社と家の往復。学生時代の友達とは少しずつ疎遠に |
| 人間関係の悩み | 職場の雑談、上司との距離感、飲み会での立ち位置。学生時代の苦手を社会人になっても引きずっている |
| 心の声 | 「大学で直しておけばよかった。社会人になったら自然にできると思ってた」 |
| 本当に欲しいもの | 仕事以外の話もできる同僚。気疲れしない人間関係 |
| 知識レベル | ビジネス書は少し読む。「アサーティブ」などの言葉は聞いたことがある |
| 視聴のしかた | 通勤電車や昼休み。字幕を見ながら音なしで見ることもある |
| メインとの関係 | 場面は大学（ゼミ・バイト・サークル）でも、仕組みは職場にも当てはまるので、そのまま届く。字幕だけで内容が分かる作りが効く |

> サブの別案：高校3年〜大学1年（これから大学の人間関係が始まる人）。
> 「入学前に知っておきたい」という見方で、メインの少し手前の悩みをかかえている層です。

## 4. キャラクターのスタイル統一ルール

主人公（丸い白頭）以外に、友人・好きな人・恋人などを増やしても絵柄がぶれないよう、全員を同じ「型」から作ります。

### 変えないもの（全員共通）
| 部位 | ルール |
| --- | --- |
| 頭 | 白い大きな丸。大きさも全員同じ（子ども・年上なども頭の大きさは同じで、体で差をつける） |
| 目・眉・口 | 同じ描き方（上が平らな半目、小さな黒目、太い眉、一本線の口）と、同じ表情の仕組み |
| 線 | 同じ太さ・同じ手描きの揺らぎ |
| 肌 | 全員白（顔・首・手） |
| 体の比率 | 同じ骨格。身長と肩幅だけ ±10% まで |

### 変えてよいもの（見分けるための部品）
| 部品 | ルール |
| --- | --- |
| ① 髪 | 頭にぴったり乗る一色の平らな形（束の線なし）。主人公だけ髪なし |
| ② 服の色 | 一人に一つのテーマカラー（主人公はグレー） |
| ③ 小物 | 一人につき一つまで（メガネ、ヘアピン、キャップなど） |
| ④ いつもの目つき | 半目の開き具合だけ変える（主人公はジト目、友人は少し開いた穏やかな目など） |

### チェック方法
- **シルエットテスト：** 全員を黒く塗りつぶしても見分けられること（主に①の髪で区別する）
- **並べて確認：** 新しいキャラは、全員を1枚に並べた静止画で確認してから使う

### 制作上のしくみ
コードでは、全員が同じ「キャラクターの型」を使い、一人分の違いは髪・色・小物・目つきを書いた短い設定だけです。
新キャラを追加しても絵柄が自動的にそろい、表情や動き（タイピング・スマホなど）も全員で使い回せます。
モブ（背景の人）は、顔なしのグレーにして制作量を抑えます。

## 5. 場面（セット）のライブラリ

参考チャンネルは1本につき2〜4個の場面を使っています。日本の大学生向けに置き換え、よく使う場面から順に作ります。

| 優先 | 場面 | 使う悩みの例 |
| --- | --- | --- |
| 1 | 自分の部屋（夜）※作成済み | 反省会、LINEの返信、寝る前のスマホ |
| 2 | 授業前の教室・ゼミ室 | 雑談、沈黙、グループワーク |
| 3 | 学食・キャンパスのコンビニ | 偶然会った知り合いとの会話 |
| 4 | サークルの飲み会（居酒屋の座敷、端の席） | 輪に入れない、話題がない |
| 5 | バイト先の控え室 | 先輩・同僚との距離感、断れない |
| 6 | 電車・帰り道 | 言えなかったことを思い出す |
| 7 | 比喩用の抽象的な空間（無地の背景） | 仕組みの説明 |

## 6. 参考チャンネルの分析メモ（NotebookLM、10本）

### 取り入れるもの
| 要素 | 参考チャンネルでの形 | このチャンネルでの形 |
| --- | --- | --- |
| 冒頭 | 痛い失敗の場面を「想像して」と語る／直感に反する事実を出す | 主人公が失敗する場面をアニメで見せる |
| 比喩 | 1本に2〜4個。日常で直感的に分かるもの | 4分版は大きな比喩1つ＋小さな比喩1つ。アニメで動かせるものを選ぶ |
| 研究 | 1本に1〜2件。物語の一節として簡潔に。仮説ははっきり断る | 同じ。「研究で分かっていること」と「目安・仮説」を言い分ける |
| 具体例 | 悪い会話と良い会話のセリフを並べる | 同じ。字幕のセリフで並べる |
| 視聴者の参加 | 一時停止クイズ、自分に当てはめる問い | 同じ |
| 高評価のお願い | 中盤（30〜50%）で、あるある行動と結びつける | 同じ |
| 終わり方 | 一文の要約＋今週の小さな行動 | 同じ。持ち帰る一言のカードで見せる |

### まねしないもの（権利と独自性のため）
- 参考チャンネル独自の概念名・造語・比喩（「Tab 1 / Tab 2」「Interview Trap」「Spark Hunt」「Echo Technique」「Doors and Threads」「カメラマンと主役」「舞台裏と客席」「漏れるバケツ」など）
- 参考チャンネルの人物（例：会話上手のMarcus）と決まり文句（「Thanks for watching and until next...」）
- 欧米の文化に依存した場面や冗談（立食パーティー、ブリトー、いじり）
- 同じ一時停止クイズの題材（例：「I just got back from Japan」を、「地元に帰ってた」に言い換えるだけ、など）。題材も自分たちで考える

### このチャンネルの違い（差別化）
1. **固定の主人公がいる：** 参考チャンネルは「あなた」に想像させるだけ。こちらは毎回同じ主人公が失敗し、少しずつ変わる。シリーズとしての親しみが育つ
2. **語り手が人格を持たない：** 参考チャンネルは「私も昔は」と語る。こちらは仕組みの整理と見せ方で信頼を作る
3. **日本の大学生の場面：** ゼミ、学食、サークルの飲み会、バイトの控え室など
4. **4分の短さ：** 寝る前に1本見られる長さ。方法を1〜2個に絞る

### 分析で分からなかったこと
- 再生回数のデータがなかったため、どのタイトルや冒頭が伸びるかは未確認
- 分析は10本分（予定は20本）
